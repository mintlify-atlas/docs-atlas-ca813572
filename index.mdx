Formbox Renderer is a headless React library that turns HL7® FHIR® Questionnaire resources into fully interactive forms. It handles form state, validation, conditional logic (`enableWhen`), calculated expressions, ValueSet expansion, and repeating groups — you supply the theme and CSS.

## What Formbox Renderer does

Formbox Renderer takes a FHIR Questionnaire resource and produces a live, interactive form. The renderer is **headless**: it owns all form logic but delegates every DOM element and style decision to a theme object you provide.

<CardGroup cols={3}>
  <Card title="FHIR R4 & R5" icon="hospital">
    Supports both FHIR R4 and R5 Questionnaire and QuestionnaireResponse resources.
  </Card>
  <Card title="SDC extensions" icon="layer-group">
    Evaluates `enableWhen`, calculated values, `launchContext`, and constraint expressions via FHIRPath.
  </Card>
  <Card title="Pluggable themes" icon="swatchbook">
    Swap in hs-theme, nshuk-theme, antd-theme, mantine-theme, or build your own.
  </Card>
  <Card title="ValueSet expansion" icon="list">
    Expands ValueSets via a terminology server — defaults to `tx.fhir.org`.
  </Card>
  <Card title="TypeScript-first" icon="brackets-curly">

  <Card title="Multilingual" icon="language">
    Switch questionnaire language at runtime; theme strings are fully localizable.
  </Card>

## Get started

<Steps>
  <Step title="Install the package and a theme">
    ```bash
    npm install @formbox/renderer @formbox/hs-theme
    ```
  </Step>
  <Step title="Import the renderer and theme">
    ```tsx
    import Renderer from "@formbox/renderer";
    import { theme } from "@formbox/hs-theme";
    import "@formbox/hs-theme/style.css";
    ```
  </Step>
  <Step title="Render your questionnaire">
    ```tsx
    const questionnaire = {
      resourceType: "Questionnaire",
      item: [
        { linkId: "name", text: "Full name", type: "string", required: true },
        { linkId: "dob", text: "Date of birth", type: "date" },
      ],
    };

    export function PatientForm() {
      return (
        <Renderer fhirVersion="r5" questionnaire={questionnaire} theme={theme} />
      );
    }
    ```
  </Step>
</Steps>

See the [Quickstart guide](/quickstart) for a full walkthrough including submit handling and response capture.
