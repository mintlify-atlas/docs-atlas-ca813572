---
title: "Quickstart: render your first FHIR Questionnaire"
description: "Install Formbox Renderer and a theme, define a FHIR Questionnaire, capture the live response with onChange, and handle submission with onSubmit."
---

This guide takes you from zero to a working FHIR-backed form. You will install the renderer and a theme, define a questionnaire with a few item types, capture the live QuestionnaireResponse via `onChange`, and handle submission with `onSubmit`.

<Steps>
  <Step title="Install the renderer and a theme">
    Install `@formbox/renderer` and a theme package. The examples below use `@formbox/hs-theme`, but any built-in theme works the same way.

    <CodeGroup>

    ```bash npm
    npm install @formbox/renderer @formbox/hs-theme
    ```

    ```bash yarn
    yarn add @formbox/renderer @formbox/hs-theme
    ```

    ```bash pnpm
    pnpm add @formbox/renderer @formbox/hs-theme
    ```

    </CodeGroup>

    <Note>
      The renderer requires peer dependencies. Install them if your project does not already have them — see [Installation](/installation) for the full list.
    </Note>
  </Step>

  <Step title="Import the renderer, theme, and CSS">
    Import the default `Renderer` component, the theme object, and the theme's compiled CSS. The CSS import is required — without it the form renders without any styles.

    ```tsx
    import Renderer from "@formbox/renderer";
    import { theme } from "@formbox/hs-theme";
    import "@formbox/hs-theme/style.css";
    ```
  </Step>

  <Step title="Define a questionnaire">
    Define a FHIR Questionnaire resource. The renderer accepts plain objects or typed resources using `QuestionnaireOf<V>`.

    ```tsx
    import type { QuestionnaireOf } from "@formbox/renderer";

    const questionnaire: QuestionnaireOf<"r5"> = {
      resourceType: "Questionnaire",
      status: "active",
      item: [
        { linkId: "first-name", text: "First name", type: "string", required: true },
        { linkId: "dob", text: "Date of birth", type: "date" },
        { linkId: "consent", text: "Consent to treatment", type: "boolean" },
      ],
    };
    ```

    The `linkId` field is required on every item. The `type` field determines which input control the renderer asks the theme to render — `"string"`, `"date"`, and `"boolean"` map to a text input, date picker, and checkbox respectively.
  </Step>

  <Step title="Capture the response with onChange">
    Pass an `onChange` callback to receive the live `QuestionnaireResponse` every time the user changes an answer. Use this to keep a copy of the response in local state or send it to an external store.

    ```tsx
    import { useState } from "react";
    import Renderer from "@formbox/renderer";
    import { theme } from "@formbox/hs-theme";
    import "@formbox/hs-theme/style.css";
    import type { QuestionnaireOf, QuestionnaireResponseOf } from "@formbox/renderer";

    const questionnaire: QuestionnaireOf<"r5"> = {
      resourceType: "Questionnaire",
      status: "active",
      item: [
        { linkId: "first-name", text: "First name", type: "string", required: true },
        { linkId: "dob", text: "Date of birth", type: "date" },
        { linkId: "consent", text: "Consent to treatment", type: "boolean" },
      ],
    };

    export function IntakeForm() {
      const [response, setResponse] = useState<QuestionnaireResponseOf<"r5">>();

      return (
        <Renderer
          fhirVersion="r5"
          questionnaire={questionnaire}
          theme={theme}
          onChange={setResponse}
        />
      );
    }
    ```

    `onChange` fires on every state change, including when the user types a single character. If you only need the final response, use `onSubmit` instead.
  </Step>

  <Step title="Handle submission with onSubmit">
    Pass an `onSubmit` callback to receive the validated `QuestionnaireResponse`. The renderer runs all validation before calling `onSubmit` — if any required fields are missing or constraints fail, the callback does not fire and errors are surfaced in the form.

    ```tsx
    import { useState } from "react";
    import Renderer from "@formbox/renderer";
    import { theme } from "@formbox/hs-theme";
    import "@formbox/hs-theme/style.css";
    import type { QuestionnaireOf, QuestionnaireResponseOf } from "@formbox/renderer";

    const questionnaire: QuestionnaireOf<"r5"> = {
      resourceType: "Questionnaire",
      status: "active",
      item: [
        { linkId: "first-name", text: "First name", type: "string", required: true },
        { linkId: "dob", text: "Date of birth", type: "date" },
        { linkId: "consent", text: "Consent to treatment", type: "boolean" },
      ],
    };

    export function IntakeForm() {
      const [response, setResponse] = useState<QuestionnaireResponseOf<"r5">>();

      function handleSubmit(submitted: QuestionnaireResponseOf<"r5">) {
        // Called only after validation passes.
        // Send to your API or store as needed.
        console.log(submitted);
      }

      return (
        <Renderer
          fhirVersion="r5"
          questionnaire={questionnaire}
          theme={theme}
          onChange={setResponse}
          onSubmit={handleSubmit}
        />
      );
    }
    ```

    The theme renders a submit button that triggers the validation-then-submit flow. Your theme must wire up a submit action for `onSubmit` to be reachable.
  </Step>
</Steps>
