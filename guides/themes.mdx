Formbox Renderer is headless: it owns all form logic but renders nothing to the DOM itself. Every visual element — labels, inputs, error messages, buttons — comes from a **theme object** you provide. Four ready-made themes are published so you can start rendering immediately without building your own.

## How themes work

Every theme package exports two things:

- A `theme` object that implements the `Theme` contract from `@formbox/theme`.
- A compiled CSS file you must import explicitly.

The renderer never imports CSS on its own. If you skip the CSS import, the form will render structurally correct HTML but with no styling.

<Note>
  The `theme` prop is required. The renderer will not accept `undefined`.
</Note>

      <Step title="Wrap the renderer with the Mantine Provider">
        The Mantine theme requires a `Provider` component wrapping the renderer so Mantine's context is available to all theme components.

        ```tsx
        import Renderer from "@formbox/renderer";
        import { Provider, theme } from "@formbox/mantine-theme";
        import "@formbox/mantine-theme/style.css";

        export function PatientForm({ questionnaire }) {
          return (
            <Provider>
              <Renderer fhirVersion="r5" questionnaire={questionnaire} theme={theme} />
            </Provider>
          );
        }
        ```
      </Step>
    </Steps>

    <Warning>
      Forgetting the `Provider` wrapper with the Mantine theme will cause runtime errors because Mantine components depend on context values that `Provider` supplies.

## Mixing and matching components

Because `theme` is a plain object, you can spread any base theme and override individual components. This lets you adopt a theme's defaults while substituting only the parts you need to change.

```tsx
import type { Theme } from "@formbox/theme";
import { theme as baseTheme } from "@formbox/hs-theme";
import "@formbox/hs-theme/style.css";
import { MyLabel } from "./my-label";
import { MySubmitButton } from "./my-submit-button";

const theme: Theme = {
  ...baseTheme,
  Label: MyLabel,
};
```

<Tip>
  Spreading a base theme and overriding a few components is the fastest path to a custom look. You get all working components immediately and can replace them incrementally.
</Tip>

## Building a fully custom theme

If none of the built-in themes fit your design system, you can implement the `Theme` contract from scratch. See [Building a theme](/themes/building-a-theme) for a step-by-step guide.
